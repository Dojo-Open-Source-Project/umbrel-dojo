Wallet instructions

Sparrow Wallet (desktop)
  1. Open Preferences › Server and pick Private Electrum, pointing it at your Electrum server — Dojo does not replace it.
  2. Dojo is used by Sparrow for PayNyms and collaborative transactions. Under Tools › Restart in Tor mode, make sure Tor is running.
  3. Use the endpoint above wherever a Dojo/Soroban backend is requested.
Ashigaru Wallet (Android)
  1. Install Ashigaru Wallet and choose Connect to existing Dojo during setup.
  2. Tap the QR scanner and scan the code above with the Tor tab selected.
  3. Finish wallet creation. Ashigaru shows a green indicator once it is talking to your Dojo.
Sentinel (watch-only)
  1. Open Sentinel and go to Settings › Connect to Dojo.
  2. Scan the code above.
  3. Add your xpubs; they are tracked by your own Dojo instead of a third-party server.
